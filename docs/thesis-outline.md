## 系统结构图（总纲，第3、4、5章共用）

```
基于Chipmunk2D的中学物理力学沙盒实验室
├── 1. 渲染系统模块
│   ├── OpenGL 渲染封装（VAO/VBO/IBO/Shader/UniformBuffer）
│   ├── 实例化绘制与纹理槽管理
│   └── 正交相机、缩放与视窗平移
├── 2. 物理系统模块
│   ├── PhysicWorld 封装（Chipmunk2D）
│   ├── 碰撞体：圆形 / 矩形 / 多边形
│   ├── 约束：绳索（Cord）/ 刚性杆（Rod）/ 弹簧（Spring）
│   └── 全局参数：重力、静/动摩擦、滑移阈值
├── 3. 组件与编辑系统模块
│   ├── Component 树形结构（父子层级）
│   ├── 变换编辑（位置/旋转/缩放：世界/相对）
│   ├── 运行态/暂停态物理-渲染双向同步
│   └── 描述组件（多行文本、参数跟随显示）
└── 4. 编辑器交互与场景管理模块（ImGui）
    ├── 添加对象（模板驱动）
    ├── 选择、属性编辑、删除
    ├── 运行/暂停模拟控制
    ├── 场景保存 / 加载 / 删除
    └── 关键操作确认弹窗 / Setting 开关
```

## 章节结构规划

### 摘要（三段）

- **第一段**：研究背景与意义——传统中学力学实验搭建成本高、参数调整不直观、实验过程难以复现，引出本课题的必要性。
- **第二段**：系统简介——本课题设计并实现了基于Chipmunk2D的中学物理力学沙盒实验室，包含渲染系统、物理系统、组件与编辑系统、编辑器交互与场景管理四大模块，分别实现了可视化渲染与交互、物理约束仿真、对象树形编辑、场景序列化与预设实验加载等功能。
- **第三段**：技术栈——系统采用C++14开发，运行于Windows平台，使用Visual Studio构建；核心依赖包括OpenGL（GLFW/GLEW）、Chipmunk2D、ImGui、nlohmann/json等；场景数据以JSON文件持久化，无需数据库。

### 第3章 系统分析与设计

**3.1 需求分析**
- 用户角色：单一用户（教师/学生）。
- 功能需求（逐条，从用户视角）：
  1. 用户可以在场景中添加多种物理对象（圆形、矩形、多边形）。
  2. 用户可以通过拖拽和属性面板编辑对象的位置、旋转、缩放及物理参数。
  3. 用户可以在对象之间添加约束（绳索、刚性杆、弹簧）。
  4. 用户可以调节全局物理参数（重力、摩擦系数等）。
  5. 用户可以启动/暂停物理模拟。
  6. 用户可以保存、加载、删除场景文件（JSON格式）。
  7. 用户可以直接加载内置预设实验（单摆、弹簧简谐、斜坡小车）。
  8. 用户可以为对象添加描述文本，文本随对象跟随显示。
- 用例图：单一角色 → 8 条用例（与上述需求对应）。

**3.2 总体设计**
